# Publier la version 0.1.0

Avant de publier, cochez chaque étape.

- [ ] Vérifier que la CI est verte sur le commit retenu.
- [ ] Vérifier que le CHANGELOG et les versions déclarées indiquent `0.1.0`.
- [ ] Vérifier le GIF de démonstration et son accès depuis GitHub.
- [ ] Vérifier la vidéo de démonstration et son accès depuis GitHub.
- [ ] Faire installer ce commit par une autre personne selon le README. Noter le système utilisé, le résultat et les difficultés.
- [ ] Obtenir l'accord écrit de Charles avant de créer le tag et la release GitHub.
- [ ] Après cet accord, créer le tag `v0.1.0` sur le commit retenu.
- [ ] Publier la release GitHub avec le CHANGELOG et les liens vers le GIF et la vidéo.
